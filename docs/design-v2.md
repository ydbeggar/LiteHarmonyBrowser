## 0. v2.1 关键结论（先看这里）

| # | 结论 | 影响 |
|---|---|---|
| 1 | **`if/elif/else` 节点不参与父级 flex 流，渲染在父容器原点**（v2.0 真机截图实证：详情页内容从 y≈0 开始，压在标题栏下） | 条件块必须作为**整屏视图容器**（自带页头，408×480），或放进 `stack` 用 `left/top` 定位 |
| 2 | `setData` 重渲染会**打断并停止 CSS 动画**（旋转环 1 秒即停的根因：`Store.init` 的 1.2s 兜底回调触发重渲染） | 加载态旋转环用 **1500ms A/B 节点交换**保活（360°≡0° 无缝），并给 `Store.init` 回调加偏好未变守卫 |
| 3 | 强调色必须取**应用图标背景蓝 `#2D6CFF`**，其余恢复 v1.x 黑底蓝字（`#64B5FF` 正文/箭头、`#1C1C1E` 卡面、`#8E8E93` 次级字、`#FF453A` 危险） | 全应用 6 页 CSS + 4 个页面 JS 同步 |
| 4 | 首页横向分页用原生 `swiper`（`index` 绑定 + `change` 事件 + 300ms），参考 FIT4 微信；`swiper` 不可直接包含 `list` | 首页菜单改为 4 个固定胶囊行（不再用 list） |

## 2. 布局规则（408×480 严格适配）

### 2.1 条件节点的正确用法

```text
错误：<div class="root"> <div class="hdr"/> <div if="...">内容</div> </div>
      → 内容渲染在 root 原点，压在页头上（v2.0 真机缺陷）

正确 A（整屏视图）：<div class="root"><div class="view" if="..."> 页头+内容 </div>
                    <div class="view" elif="..."> 页头+内容 </div></div>
正确 B（层叠区）：  <stack class="body"> <list if="..."/> <div else/> </stack>
```

## 3. 动效（v2.1 修订）

| 通道 | 规格 | 说明 |
|---|---|---|
| 入场 `lwb-in` | 280ms ease-out，opacity 0→1 + translateY 12→0 | `if` 插入即播；只用于整屏视图/状态层 |
| 翻页 `lwb-turn` | 160ms 纯淡入 | 阅读页 A/B 双缓冲文本层 |
| 旋转环 `lwb-spin` | 1500ms linear infinite，52×52 圆环（`#64B5FF` 亮段 + `#1C1C1E` 暗段） | **JS 每 1500ms 交换 A/B 节点保活**（`spinA`），加载结束 `stopSpinner()` |
| 列表换页 | fade.js 5 步 ×32ms ease-out | 同节点内容更新 |
| 右滑返回 | 阈值 100px | LW-BACK-01（微信实证） |

**保活原理**：CSS 动画随节点重渲染停止；每 1500ms 交换两个同款节点，新节点插入重新播放一圈，
交换发生在 360°≡0° 处，视觉无缝；若动画被中途打断，最迟 1.5s 内自动重播。

### 6.4 搜索页（彻底绝对定位，修复真机叠压）

v2.1 的「整屏 view + flex」在真机上仍出现标题压页头（截图实证）。v2.2 改为**全绝对定位**：

```text
root(stack) → view(stack, if/elif) → [hdr(s-hdr 16,48 376×52)] + [detail(s-detail 16,108 376×364)]
                                   detail 内全部使用 s-* 类显式 left/top：
                                   title(0,0) sub(0,62) sum(0,92) url(0,218) foot(0,250)
list 分支：bar(0,0) status(0,60) area(stack 0,88 376×268) → 状态块/列表/分页均在 area 内
```

结论：**条件分支内的 flex 布局不可依赖**，分支内一律使用 `stack` + `left/top` 显式坐标；
这条规则已写入 `docs/HANDOVER.md` 与技能参考 `hml-lite-syntax.md`。

## 7. v2.3 修订：状态行删除 / 放大镜加载 / 阅读页操作页 / 长摘要滚动 / 离线保存

- 36×36 纯 CSS 放大镜（24 圆环 + 斜柄），容器 64×64 **保证旋转不裁切**；
- `rotate 1500ms linear infinite`；配合 1500ms A/B 节点交换保活（防 setData 打断）；
- 阅读页与搜索页统一。

### 7.3 阅读页：底部常驻按钮改为右侧滑出操作页
- 阅读页 = 页头 + 正文 **320**（原 292）+ 页码行；不再有底部「链接/收藏/设置」；

### 7.4 网页摘要：加长 + 可滚动 + 居中
